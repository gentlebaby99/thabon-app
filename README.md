# ระบบโรงเรียนท่าบอนมิตรภาพที่ 90

แอปเดียวรวมทุกงานของโรงเรียน (Portal) ล็อกอินครั้งเดียวด้วยบัญชี Google
สร้างบน **Google Apps Script + Google Sheets** — ฟรี ไม่มีค่าเซิร์ฟเวอร์

> เวอร์ชันนี้ = **ครบทั้ง 6 ระบบ** + หน้าผู้ดูแลระบบ + แจ้งเตือนในแอป/อีเมล
> 📋 เช็คชื่อ (แดชบอร์ด + ประวัติ + Export รายเดือน) · 📝 ระบบลา · 📚 ส่งแผนการสอน
> 📨 สารบรรณ E-Office · 🗂️ จัดเก็บเอกสาร 4 ฝ่าย · 📊 ผลสอบ RT/NT/O-NET

## ภาพรวมสถาปัตยกรรม

| ส่วน | รายละเอียด |
|---|---|
| **ล็อกอิน** | แพลตฟอร์ม Apps Script บังคับเข้าสู่ระบบด้วย Google เอง แล้วระบบดูอีเมลผ่าน `Session.getActiveUser()` — ปลอมไม่ได้ ไม่ต้องตั้งค่า OAuth |
| **สิทธิ์** | ตามบทบาท (admin / principal / teacher / staff) + ปรับรายคนได้ (คอลัมน์ `extraPerms`) |
| **ข้อมูล** | ไฟล์กลาง 1 ไฟล์ (Users / Students / Apps / Config / Log / Notifications) + ไฟล์ระบบเช็คชื่อแยกอีก 1 ไฟล์ |
| **เจ้าของ** | บัญชีที่รัน `setupSystem()` (เริ่มต้น: **gentleboy9@gmail.com** = ครูเหวิน) |

### รายชื่อไฟล์ในโปรเจกต์ (โฟลเดอร์ `src/`)

**ไฟล์ Script (`.gs`)** — สร้างเป็นชนิด *Script*
`Config` · `Schema` · `Data` · `Auth` · `Permissions` · `Students` · `Attendance` · `Notifications` · `Setup` · `Code` · `SeedStudents` · `SeedUsers`

**ไฟล์ HTML** — สร้างเป็นชนิด *HTML* (ชื่อ **ตรงตามนี้เป๊ะ** ตัวพิมพ์ใหญ่-เล็กสำคัญ)
`Index` · `Styles` · `JavaScript`

**ไฟล์ manifest** — `appsscript.json` (เปิดให้เห็นในตั้งค่าโปรเจกต์)

## วิธีติดตั้ง (ทำครั้งเดียว)

> ทำโดยบัญชี **เจ้าของระบบ** (gentleboy9@gmail.com / ครูเหวิน)

### วิธีที่ A — คัดลอกวาง (แนะนำ ไม่ต้องลงโปรแกรมอะไร)

1. ไปที่ **https://script.google.com** → *New project* (โปรเจกต์ใหม่)
   ตั้งชื่อโปรเจกต์เช่น “ระบบโรงเรียนท่าบอน”
2. **เปิดให้เห็น manifest:** ⚙️ Project Settings → ติ๊ก *“Show appsscript.json manifest file in editor”*
3. **สร้างไฟล์ให้ครบ** ตามรายชื่อด้านบน
   - ไฟล์ `.gs` แต่ละไฟล์: กด **+ → Script** ตั้งชื่อ (ไม่ต้องพิมพ์ `.gs`) แล้ววางเนื้อหาจากไฟล์ในโฟลเดอร์ `src/`
   - ไฟล์ HTML (`Index`, `Styles`, `JavaScript`): กด **+ → HTML** ตั้งชื่อให้ตรง แล้ววางเนื้อหา
   - เปิดไฟล์ `appsscript.json` ที่โผล่มา แล้ววางเนื้อหาจาก `src/appsscript.json` ทับ
   - ลบไฟล์เริ่มต้น `Code.gs` ที่ Google สร้างให้ถ้าซ้ำ (ให้เหลือ `Code` ของเราไฟล์เดียว)
4. **รันตัวติดตั้ง:** เลือกฟังก์ชัน `setupSystem` ที่แถบด้านบน → กด **Run**
   - ครั้งแรกจะขอสิทธิ์ → *Review permissions* → เลือกบัญชีเจ้าของ →
     ถ้าเจอ *“Google hasn’t verified this app”* ให้กด **Advanced → Go to … (unsafe)** → **Allow**
     (ปกติ เพราะเป็นแอปภายในที่เรายังไม่ได้ส่ง Google รับรอง)
   - เมื่อรันเสร็จ ดูผลใน **Execution log** จะเห็นลิงก์ไฟล์ Sheet 2 ไฟล์ที่สร้างให้ + ข้อความ “ติดตั้งสำเร็จ”
   - ระบบจะ **นำเข้านักเรียน 83 คน + ผู้ใช้ 5 คน** และ **แชร์ไฟล์ให้ครูทั้ง 5 อัตโนมัติ**
5. **Deploy เป็นเว็บแอป:** กด **Deploy → New deployment** → เลือกชนิด *Web app*
   - **Execute as:** `User accessing the web app` (ผู้ใช้ที่เข้าถึง)
   - **Who has access:** `Anyone with Google account` (ต้องเข้าสู่ระบบ Google)
   - กด **Deploy** → คัดลอก **Web app URL**
6. **แจกลิงก์** ให้ครูทั้ง 5 คน เปิดในมือถือ/คอม → เข้าสู่ระบบด้วย Google → กดอนุญาตสิทธิ์ (จะเจอหน้าเตือน unverified เช่นเดียวกัน ให้กด Advanced → Allow ครั้งเดียว)

### วิธีที่ B — ใช้ clasp (สำหรับผู้ถนัดเทคนิค)

```bash
npm install -g @google/clasp
clasp login
clasp create --type webapp --title "ระบบโรงเรียนท่าบอน" --rootDir ./src
# นำ scriptId ที่ได้ไปใส่ใน .clasp.json (มีไฟล์ตัวอย่างให้แล้ว)
clasp push
```
จากนั้นเปิดโปรเจกต์ (`clasp open`) แล้วทำ **ขั้นตอนที่ 4–6** ของวิธี A

## หลังติดตั้ง — งานที่ผู้ดูแล (แอดมิน) ควรทำ

ทำได้ในแอปเลย เข้าเมนู **⚙️ ผู้ดูแลระบบ** (เห็นเฉพาะบัญชี role = admin เช่น ครูเหวิน) มี 2 แท็บ:

**แท็บ “ครู / ผู้ใช้”**
- **กำหนดครูประจำชั้น:** กดแก้ไขครู → เลือกช่อง “ครูประจำชั้น”
- **กำหนด ผอ.:** เพิ่ม/แก้ผู้ใช้ → ตำแหน่ง = ผู้อำนวยการ (จะเป็นคนอนุมัติลา/แผนในระบบถัดไป)
- **เพิ่มผู้ใช้ใหม่:** กด “+ เพิ่มผู้ใช้” → ระบบพยายามแชร์ไฟล์ให้อัตโนมัติ
  (ถ้าขึ้นว่าแชร์ไม่สำเร็จ ให้เจ้าของรันฟังก์ชัน `reshareDataFiles` ใน Apps Script หนึ่งครั้ง)
- **เปิด/ปิดบัญชี:** สลับสวิตช์ “เปิดใช้งานบัญชี” (ไม่ลบทิ้ง เพื่อคงประวัติ)

**แท็บ “นักเรียน”** — เพิ่ม/แก้/ย้ายชั้น/ตั้งสถานะ “ออกแล้ว” ได้ครบ

> หมายเหตุ: การแก้โดยตรงในไฟล์ Sheet ก็ยังทำได้ แต่แนะนำให้ใช้หน้าแอดมินเพื่อความถูกต้อง

## เรื่องความปลอดภัยที่ควรทราบ

เพราะเว็บแอปรัน “ในนามผู้ใช้ที่เข้าถึง” ไฟล์ Sheet ทั้งสองจึงถูก **แชร์แบบแก้ไขได้** ให้บัญชีครูทั้ง 5
หมายความว่าครูเปิดไฟล์ Sheet ดิบได้โดยตรง (จึงควรใช้กับบุคลากรที่ไว้ใจ) ทุกการบันทึกมีเก็บ log ในชีต `Log`
หากต้องการล็อกให้แน่นขึ้นในอนาคต แนะนำย้ายไปใช้ **Google Workspace for Education** ของโรงเรียน

## จะเปลี่ยนโลโก้/ชื่อ
- โลโก้ตอนนี้เป็นตัวอักษรวงกลม “ท.๙๐” (ในไฟล์ `Index.html` และ `Styles.html`)
  เปลี่ยนเป็นรูปจริงได้โดยฝังรูปแบบ data URI ในภายหลัง
- ชื่อโรงเรียน/ปีการศึกษา แก้ที่ `Config.gs`

## สรุปการทำงานแต่ละระบบ

| ระบบ | ใครใช้ | การทำงานหลัก |
|---|---|---|
| 📋 เช็คชื่อมาเรียน | ครู/ผอ./แอดมิน | แดชบอร์ดภาพรวมวันนี้ → เลือกชั้น → ติ๊กรายคน (มา/สาย/ลา/ขาด) → ดูประวัติ + **Export สรุปรายเดือนเป็น Google Sheet** (แยกชีตตามชั้น พร้อมสรุปรายคน) |
| 📝 ระบบลา | ทุกคน | ยื่นใบลา (คำนวณวันให้) → ผอ./แอดมินอนุมัติขั้นเดียว → แจ้งอีเมลสองทาง · ยกเลิกใบลาที่รอได้ |
| 📚 ส่งแผนการสอน | ครู + ผอ. | ครูส่งแผนรายเดือน (ลิงก์ไฟล์) → ผอ.ตรวจ ผ่าน/ให้แก้ไข + หมายเหตุ → แจ้งอีเมล |
| 📨 สารบรรณ E-Office | ธุรการ/ผอ./แอดมิน | ลงทะเบียนหนังสือรับเข้า/ส่งออก/เวียน/คำสั่ง · ชั้นความเร็ว · มอบหมายผู้รับผิดชอบ (แจ้งเตือนคนถูกมอบหมาย) · ติดตามสถานะ |
| 🗂️ จัดเก็บเอกสาร | ธุรการ/ผอ./แอดมิน | คลังเอกสารกลาง แยกฝ่าย/หมวด/ปีการศึกษา ค้นหาได้ ลบได้เฉพาะแอดมิน/เจ้าของ |
| 📊 ผลสอบ RT/NT/O-NET | ครู/ผอ./แอดมิน | บันทึกคะแนนรายวิชา (โรงเรียน/เขต/ประเทศ) ดูตารางเทียบรายปี สีเขียว=สูงกว่าประเทศ กรอกปี+วิชาซ้ำ=แก้ของเดิม |
| 🔔 แจ้งเตือน | ทุกคน | กระดิ่งมุมขวาบน มีตัวเลขแจ้งจำนวนที่ยังไม่อ่าน เปิดดูแล้วถือว่าอ่านแล้ว |

ค่าที่ปรับแต่งได้ (ประเภทการลา, ประเภทหนังสือ, ฝ่าย, หมวดเอกสาร, วิชาสอบ ฯลฯ) อยู่ที่ `Config.gs` ทั้งหมด
— แก้แล้วรัน `setupSystem()` ซ้ำหนึ่งครั้ง (ปลอดภัย รันซ้ำได้เสมอ ทะเบียนระบบจะ sync อัตโนมัติ)
